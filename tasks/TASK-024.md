# TASK-024: 前面カメラの向き補正を接続の実測値ベースにする

- status: in-progress
- priority: critical
- started_at: 2026-07-30

## 症状

前面カメラに切り替えると、縦持ちでプレビューが横向き（頭の頂点が左）になる。
保存した写真も横向きで、さらに左右反転している。背面は正常。

TASK-019（設定タイミングの修正）でも直らず、
本タスクの第 1 案（接続を無効に固定してコード側で回す）でも直らなかった。

## 原因

`AVCaptureConnection` への `videoRotationAngle` / `isVideoMirrored` の設定は、
入力を張り替えた直後だと**エラーも警告もなく適用されない**。

そのため「設定したつもりの値」と「実際にバッファへ適用された値」がずれる。

| | 接続の実際の回転 | 届くバッファ | 第 1 案でソフト適用 | 結果 |
|---|---|---|---|---|
| 背面 | `0`（設定が効く） | 横向き（生） | `.right`（+90 度） | 正常 |
| 前面 | **`90` のまま**（設定が効かない） | **すでに縦向き** | `.leftMirrored`（+90 度 + 反転） | **二重回転で横向き + 鏡像** |

前面では初回構成（背面）で設定した 90 度が接続に残ったままバッファが届く。
第 1 案の `resetConnectionTransforms()` で 0 に戻そうとしたが、
それも同じ理由で適用されず、「既定値と同じだから壊れない」という前提が誤りだった。

## 修正

設定値を前提にするのをやめ、**接続から読み戻した実測値**を基準にする。

- `CameraOrientation.remaining(appliedRotation:appliedMirroring:mirrored:)`
  … 接続が既に適用した変換を差し引き、残りの向きだけを返す
- プレビュー: `captureOutput` に渡ってくる `connection` から実測値を読む
- 撮影: `photoOutput.connection(with: .video)` から実測値を読む
- 接続への設定は一切行わない（効くか効かないかに依存しない）

接続の設定が効いても効かなくても、最終的な表示向きは同じになる。

| 接続の実測 | mirrored | 返す向き |
|---|---|---|
| 0 度 / 反転なし | false | `.right` |
| 0 度 / 反転なし | true | `.leftMirrored` |
| 90 度 / 反転なし | false | `.up`（追加回転なし） |
| 90 度 / 反転なし | true | `.upMirrored` |
| 90 度 / 反転あり | true | `.up`（二重反転しない） |

鏡像はプレビューのみ。保存画像は反転しない（iOS 標準の挙動に合わせる）。

## 最終的な切り分け（実機 4 回の観測）

| 経路 | 接続のプロパティ | 実際 | 採用した方法 |
|---|---|---|---|
| プレビュー | 「回転 0」と返す | 前面は縦向きで届く | **バッファの形**（横長/縦長）から回転を決める |
| 写真 | 「回転 90」と返す | 生の横向きのまま | **EXIF に任せる**（AVFoundation が正しく書く） |

接続のプロパティは設定も読み取りも実態と一致しない。
経路ごとに実態が違うので、共通の計算式にまとめようとした試みが 3 回とも失敗した。

写真については**元の実装（EXIF 適用）が正しかった**。
壊していたのは、こちらが接続へ書き込んでいた回転・ミラー設定のほう。
その書き込みを全廃したので EXIF に戻せる。

## それでもずれていた場合

プレビュー左上に一時的なサイズ表示を 2 行出してある。

- `表示 1440x1920 縦長` … プレビューに届いたフレーム（補正後）
- `写真 3024x4032 縦長` … 直近の撮影データ（EXIF 適用後）

どちらも**縦長になっていれば向きは合っている**。撮影すると 2 行目が出る。

| 表示 | 意味 / 次の手 |
|---|---|
| 写真が横長 | EXIF が効いていない。`applyOrientationProperty` を確認する |
| 写真は縦長だが上下逆さま | EXIF は効いている。180 度は別要因 |
| 表示が横長 | プレビューの形の判定が想定と違う。`.right` の向き（`.left`）を疑う |

サイズ表示は `CameraView.previewSizeReadout` /
`CameraViewModel.previewFrameSize` / `lastPhotoSize` にある。
向きが確定したら全部削除する。

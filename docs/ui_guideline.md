# UI Guideline

## 原則

- **すぐ撮れる**: 起動から撮影まで最短。設定画面より撮影画面を優先する
- **Simple / Stylish / Fun**: 装飾は最小限、質感で魅せる
- 「カメラアプリ」としての UI。加工アプリの UI（スライダー羅列等）にしない

## 画面構成（MVP）

```text
┌─────────────────────┐
│  プリセット名 / 切替       │ ← 上部: 現在のカメラ表示
│ ┌─────────────────┐ │
│ │                 │ │
│ │  中央フレーム       │ │ ← 保存される領域を明示
│ │  (プレビュー)       │ │
│ │                 │ │
│ └─────────────────┘ │
│                     │
│  [切替]  ◉  [プリセット]  │ ← 下部: シャッター中心
└─────────────────────┘
```

## ルール

- 中央フレームは **3:4 固定**（プリセットによらず共通）
- 中央フレームの外側は暗くして「保存されない領域」を直感的に伝える
- シャッターボタンは画面下部中央、片手で届く位置に固定
- プリセット切り替えは横スワイプ or 横スクロールで 1 アクション
- 文字は最小限。アイコンと視覚表現で伝える
- ダークベースの配色（カメラアプリとして没入感を優先）

## フィードバック

- シャッター時: 視覚（フラッシュ/フレーム点滅）+ 触覚（Haptics）
- 保存完了: 控えめなサムネイル表示。モーダルやアラートは出さない
- 権限拒否時のみ、設定アプリへの導線を明示する

## アクセシビリティ

- タップ領域は 44pt 以上
- Dynamic Type はプリセット名など文字要素で対応

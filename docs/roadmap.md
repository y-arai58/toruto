# Roadmap

## Phase 1（MVP）

撮影パイプライン（撮る → 加工 → 保存）を縦に通す。

- [x] カメラ起動（権限・AVCaptureSession）
- [x] リアルタイムプレビュー
- [x] シャッター撮影
- [x] 中央フレーム Crop
- [x] 撮影時フィルター適用
- [x] 加工済み画像の保存
- [x] カメラプリセット切り替え
- [ ] UI 改善

## Phase 2

カメラのラインナップと使い勝手を広げる。

- [ ] カメラ追加（CCD / Film / Compact）
- [ ] 撮影パラメータの調整
- [ ] お気に入り登録
- [ ] フラッシュエフェクト
- [ ] 日付スタンプ

## Phase 3

体験の拡張。

- [ ] 新しいカメラパックの追加
- [ ] カスタムプリセット
- [ ] シャッター音切り替え
- [ ] レンズ切り替え
- [ ] ランダムカメラ
- [ ] 撮影履歴
- [ ] iCloud 同期（検討）

## 実装順の方針

1. **Phase 1-a**: CameraService → プレビュー → シャッター
2. **Phase 1-b**: ImageProcessor（Crop → Filter） → 保存 → プリセット切替 UI
3. 縦のパイプラインが通ってから、横（プリセット数・UI）を広げる
